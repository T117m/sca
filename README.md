# sca - Simple Cellular Automata

A simple program for launching 2D cellular automata with custom rulestrings and dimensions that can be paused and edited. The default rulestring is b3/s23 with dimensions 100 by 50 cells, 117 miliseconds per tick and 15 pixels cell scale.
